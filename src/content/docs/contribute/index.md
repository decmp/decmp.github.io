Joining an existing decomp is the easiest way to start. The build works, the tools are set up, the hard decisions
are made, and people can review your first matches.

## What this page will cover

- **Finding a project:** browse [decmp.dev](https://decmp.dev) by console, and look for active ones.
- **Reading the README and contributing guide:** how to build, which game version to use, the naming rules.
- **Setting up:** your own copy of the game, the dependencies, the first build.
- **Saying hello:** most projects coordinate in a chat server or issues; ask what is free to work on.
- **Your first pull request:** one small function, matched and readable, with the build passing.
- **Review:** what reviewers look for, and how the progress comment on your pull request helps.

Meanwhile, [the matching workflow](/matching/workflow/) covers what you'll do once you've picked a function.
