No necesitas ser experto para empezar. Necesitas leer C con soltura, estar dispuesto a leer ensamblador con calma y
saber suficiente git para enviar un pull request. El resto lo aprendes haciendo matching.

## Qué cubrirá esta página

- **C:** punteros, structs, arrays, tipos enteros y sus tamaños, casts, y cómo el compilador organiza un struct en
  memoria.
- **Ensamblador:** registros, cargas y almacenamientos, saltos, convenciones de llamada. Necesitas leerlo, no
  escribirlo.
- **La CPU de tu consola:** MIPS, PowerPC o ARM, y su convención de llamada.
- **Herramientas:** git, Python, un sistema de build (a menudo ninja o make) y una herramienta de diff como
  [objdiff](https://github.com/encounter/objdiff).
- **Una copia legal del juego** y una forma de extraer sus archivos.
- **Paciencia.** Algunas funciones toman minutos; otras, semanas.
