La mayoría de las herramientas de decomp son gratuitas, de código abierto y compartidas entre proyectos. Esta página
será el mapa: qué herramienta hace cada tarea, y qué consolas soporta.

## Qué cubrirá esta página

| Tarea | Herramientas para empezar |
|---|---|
| Dividir un binario | [splat](https://github.com/ethteck/splat), [decomp-toolkit](https://github.com/encounter/decomp-toolkit), [ds-decomp](https://github.com/AetiasHax/ds-decomp) |
| Generar un borrador en C desde ensamblador | [m2c](https://github.com/matt-kempster/m2c) |
| Comparar y medir | [objdiff](https://github.com/encounter/objdiff), [asm-differ](https://github.com/simonlindholm/asm-differ) |
| Compartir una función | [decomp.me](https://decomp.me) |
| Probar variaciones | [decomp-permuter](https://github.com/simonlindholm/decomp-permuter) |
| Ejecutar compiladores antiguos de Windows | [wibo](https://github.com/decompals/wibo) |
| Seguir el progreso | [decmp.dev](https://decmp.dev), consulta [Sube tu progreso](/es/progress/upload-action/) |

Cada herramienta tendrá una sección breve: qué hace, qué necesita y un enlace a su propia documentación.
