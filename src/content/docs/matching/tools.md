Most decomp tools are free, open source, and shared between projects. This page will be the map: which tool does
which job, and which consoles it supports.

## What this page will cover

| Job | Tools to start from |
|---|---|
| Split a binary | [splat](https://github.com/ethteck/splat), [decomp-toolkit](https://github.com/encounter/decomp-toolkit), [ds-decomp](https://github.com/AetiasHax/ds-decomp) |
| Draft C from assembly | [m2c](https://github.com/matt-kempster/m2c) |
| Diff and measure | [objdiff](https://github.com/encounter/objdiff), [asm-differ](https://github.com/simonlindholm/asm-differ) |
| Share a function | [decomp.me](https://decomp.me) |
| Try variations | [decomp-permuter](https://github.com/simonlindholm/decomp-permuter) |
| Run old Windows compilers | [wibo](https://github.com/decompals/wibo) |
| Track progress | [decmp.dev](https://decmp.dev), see [Upload your progress](/progress/upload-action/) |

Each tool will get a short section: what it does, what it needs, and a link to its own documentation.
