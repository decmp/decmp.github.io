# decmp.dev

The published build of [decmp.dev](https://decmp.dev), a decompilation progress tracker. The site lives on the
`gh-pages` branch and is rebuilt automatically every six hours.

**Want your game listed?** [Open an issue](https://github.com/decmp/decmp.github.io/issues/new) with the
repository's `owner/repo`. The project must already upload its objdiff report to decomp.dev.
